ZEE TRADE MASTER — TradingView Live Edition
===========================================

یہ ورژن مکمل طور پر TradingView کے ساتھ لنک کر دیا گیا ہے (پاکستان سٹاک ایکسچینج کا لنک ختم کر دیا گیا ہے)۔

1) کمپیوٹر پر چلانے کا سب سے آسان طریقہ:
   - بس index.html پر ڈبل کلک کریں (یا START_LOCAL_PC_AND_WIFI.bat چلائیں)۔
   - TradingView کے تمام لائیو چارٹس، ٹیکنیکل میٹر، فنانشلز، سکرینر اور ٹکر ٹیپ خود بخود چل پڑیں گے!

2) Render.com + GitHub پر اپلوڈ کر کے موبائل اور کمپیوٹر دونوں پر چلانا:
   - GitHub پر اپنی repository میں یہ فائلیں اپلوڈ کر دیں:
     index.html, app.py, requirements.txt, render.yaml, manifest.json, icon.svg
   - Render.com پر Deploy کریں، آپ کا مستقل لنک تیار ہو جائے گا۔
